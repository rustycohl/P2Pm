# P2Pm

Point to Point Media artifact work, evidence binding, and portable ownership state.

This is an independent Ground Zero Games server-card port:

- repository: `rustycohl/P2Pm`
- Page: https://rustycohl.github.io/P2Pm/
- flag: `DEDICATED_REPO_PAGE`
- status: `alpha`
- dependencies: `ORACLE`

This alpha proves browser SHA-256 mint work; peer transport and yield are not implemented.

## Verify

```text
npm test
```

The Page runs the same browser-compatible self-test. It has no external
runtime dependency and does not introduce game-server authority.
